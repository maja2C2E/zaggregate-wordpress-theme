ZAGGREGATE Research WordPress Theme — v1.0

INSTALLATION
1. In WordPress go to Appearance > Themes > Add New > Upload Theme.
2. Upload zaggregate-theme.zip and activate it.
3. WordPress will use front-page.php as the project homepage automatically.
4. Go to Appearance > Customize > ZAGGREGATE project settings to update:
   - official calls URL
   - project contact email
   - homepage title
   - homepage introduction
5. Go to Settings > Permalinks and click “Save Changes” once after activation so all project routes are refreshed.
6. The responsive primary navigation and dropdown menus are built into the theme.

PROJECT ROUTES
- /project-overview/
- /research-programme/
- /team-partners/
- /open-positions/
- /university-of-zagreb-positions/

NOTES
- The theme has no paid plugins or page-builder dependency.
- Project images and institutional logos are bundled with the theme.
- For a bilingual website, use Polylang or WPML after institutional approval.
